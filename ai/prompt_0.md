




# Features

1. Make a third-person exploration, creature collection, light action-adventure game based on the story in ai/snuggle_sorcery_story.md
    - use three.js
    - and if required, a Physics engine of your choice, e.g., rapier
2. Create game assets, e.g., buildings, and rigged and animated characters through Blender MCP
    - use glb files
    - less substantial assets can be generated in Javascript
3. Reference photos are stored in ref (, which is not tracked in git) on both
    - environment
    - characters
4. Loading page and pause screen should have a "fork me on github" link to encourage adaptation
